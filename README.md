## 💼 Featured Projects

### 🧠 AI-Powered Recruiting Platform &nbsp;`Apr 2026 – Present`
> *Agentic AI · LangGraph · LLMs · RAG · NestJS · React · PostgreSQL/pgvector · Qdrant · Redis · MinIO · Docker*

Agentic platform that discovers, evaluates, enriches, and ranks candidate profiles against job requirements using structured skill matching and evidence-based candidate intelligence. Combines LLM reasoning, tool calling, skill extraction, embeddings, and vector search to turn recruiter inputs into **explainable candidate recommendations**, with provenance, consent, and prompt-versioning built into an event-driven architecture.

[![Repo](https://img.shields.io/badge/View_Repo-181717?style=for-the-badge&logo=github&logoColor=white)](https://github.com/SubrahmanyamNandham)

---

### 🏥 Agentic AI for Outpatient Healthcare Workflow Automation &nbsp;`Aug 2026 – Oct 2026`
> *Python · FastAPI · React.js · TypeScript · Supabase · PostgreSQL · LangChain · RAG · Twilio*

Agentic system that streamlines outpatient workflows — patient support, appointment scheduling, consultation documentation, and follow-up coordination. Includes an AI documentation pipeline that turns consultation transcripts into structured clinical drafts and flags missing or inconsistent information, plus a **human-in-the-loop review flow** where doctors approve everything before it reaches patients.

[![Repo](https://img.shields.io/badge/View_Repo-181717?style=for-the-badge&logo=github&logoColor=white)](https://github.com/SubrahmanyamNandham)

---

### 🌍 TravelMitra — AI Travel Planning Platform
> *Python · FastAPI · React.js · OpenAI · RAG · Qdrant · Apify*

Converts user preferences, destination, budget, and duration into structured, personalized itineraries. Combines LLM reasoning with tool-based retrieval (Apify) and semantic search (Qdrant), served by a FastAPI backend with authentication, structured JSON responses, and persistence, plus a responsive React.js frontend.

[![Repo](https://img.shields.io/badge/View_Repo-181717?style=for-the-badge&logo=github&logoColor=white)](https://github.com/SubrahmanyamNandham)
